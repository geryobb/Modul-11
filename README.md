this module focuses on the use of logical operators, specifically the if and if-else syntax
This module has some unexpected issues when doing the problem sets, those issues are the following:
- an overlapping in the prompt to input the value for the Scanner in the nomo2 file. the problem revolves around the act of pressing enter and it counting as an input for the next scanner, in short the scanner asked for an integer (30) then when we press enter the scanner counts the act of pressing enter as \n which is not an integer. that means the current scanner disposes the \n but doesnt delete it, when the next scanner input asked for a name in the form of a string the previous \n input acts like the input for the current scanner.
- next issue is not really an issue but still worth to be noted and that is the use of bitwise operators in the Animals file. in short a bit wise operator is similar to the logical operator, the only difference is in how they operate. a bitwise operator operates through the CPU's logic gate (AND or NAND i believe) instantly checking both conditions simultaneously, while the regular logical operators act like step-by-step checking the conditions in the if code. this step-by-step process uses more CPU power but is usually easier to read.
